🌌 星枢 StarPivot — 天文摄影 AI 智能控制台

一句话介绍

用中文指挥你的整套天文设备。 星枢是 N.I.N.A 的 AI 智能中控——你说人话,它替你操作望远镜、相机、导星、滤镜轮,并全程监控整个观测系统。



你能得到什么

🗣 像聊天一样控制设备



不用记菜单、不用看英文插件、不用背参数。

🖥 监控大屏

- 实时画面 — 拍摄时自动显示最新曝光
- 9类设备状态 — 赤道仪/相机/导星/电调/滤轮…8秒刷新
- 气象监控 — 云量/湿度/风速,异常红标告警
- 趋势曲线 — 天况转好还是变坏、对焦点有没有漂移,一眼看出
- 红光模式 — 保护夜间暗适应

🧠 懂天文的大脑

- 137 个深空目标星表,按你的焦段/季节智能推荐
- 告诉你每个目标今晚几点过中天(黄金拍摄窗口)
- 自动避开月亮附近的目标
- 拍摄参数计算:你的相机+焦距,问一句就出完整参数

📊 越用越懂你

- 自动记录每晚拍摄 → "巫师星云我拍了多久了?" 秒答
- 一键生成观测报告



使用条件

需要 | 说明

Windows 电脑 | Win10/11,普通配置即可
N.I.N.A | 免费天文控制软件(大概率你已经装了)
Advanced-API 插件 | NINA 里免费在线安装,装完重启 NINA 即可
一个模型 API Key | 推荐 DeepSeek(几块钱能用很久);智谱/Kimi/通义/OpenAI 都支持

三步上手

1. 双击 星枢.exe
2. 设置里填 API Key → 点"测试连通" → 显示 ✅
3. 问它:"今晚拍什么?"

就这么简单。

常见疑问

Q: 会被杀毒软件拦吗?
可能。因为 exe 没有付费买签名证书。添加信任即可,源码绝对干净(GitHub 开源可查)。

Q: 我的设备支持吗?
NINA 能驱动的都支持:ZWO/QHY 相机、信达赤道仪、PHD2 导星、ASI 滤轮、各种电调……

Q: 我的 Key 安全吗?
Key 只存在你自己电脑的配置文件里,不会上传到任何服务器。

Q: 费用?
星枢本身免费开源。只有调用 AI 模型产生费用(比如 DeepSeek 一晚上聊 100 句也就几分钱)。
